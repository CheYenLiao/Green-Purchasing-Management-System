# Green Purchasing Management System

## Overview
An academic group project developed for UQ’s BISM2207 Managing Business Data course. This project designs a relational database to support sustainable purchasing decisions in a proposed Brisbane 2032 Olympics scenario.

The system organizes product, supplier, venue, sport, service, and rating data to evaluate carbon footprints and product reusability.

## Project Objectives
- Support sustainable product and supplier selection.
- Identify products and activities associated with high carbon emissions.
- Provide SQL reports to inform procurement and resource management decisions.

## Skills Demonstrated
- Relational database design and entity relationship diagrams (ERDs)
- SQL table creation and sample data insertion
- Multi-table JOINs, aggregate functions, GROUP BY, filtering, and sorting
- Data validation, security controls, and data quality planning
- Translating business requirements into database reports

## SQL Reports
The project includes six reports:
1. Product options based on average carbon footprint and user ratings
2. Top three products with the highest carbon footprints within a selected period
3. Supplier evaluation based on recyclable product percentages
4. Carbon emission summaries by service
5. Top three sports by total carbon emissions
6. Reusable products with the highest rating score
